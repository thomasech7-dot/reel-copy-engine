# REEL COPY ENGINE 1.0

**Dein KI-Copywriting-Workflow für Kurzvideos. Von der Idee zum fertigen Skript.**

Ein kostenloser, eigenständiger Skill für Creator, Selbstständige und Unternehmen. Entwickelt von Thomas Olesch.

## Acht Module

Zielgruppenanalyse · Hooks · Storytelling · Reel-Skript mit Timing · Caption · CTA · Sprachoptimierung · Qualitätsprüfung.

## Schnellstart ohne Installation

1. Öffne [SKILL.md](./SKILL.md) und kopiere den Inhalt.
2. Füge ihn in einen neuen Chat bei ChatGPT oder Claude ein.
3. Ergänze dein Briefing. Die KI erstellt die gewünschten Texte anhand der Anleitung.

## Als Skill nutzen

Lade über **Code → Download ZIP** die Dateien herunter und entpacke sie. Wenn deine ChatGPT- oder Codex-Umgebung den Skill-Import unterstützt, importiere die SKILL.md bzw. den Skill-Ordner über die entsprechende Skills-Verwaltung. Alternativ nutze den Schnellstart oben.

Der Skill benötigt keine zusätzlichen Plugins, Node.js oder API-Schlüssel. Die Nutzungsgrenzen und Funktionsverfügbarkeit deines KI-Anbieters gelten weiterhin.

## Beispielprompts

- „Nutze den Reel Copy Engine für ein 30-Sekunden-Reel für einen Personal Trainer. Ziel: Anfragen. Gib mir Hook, Sprechertext, Szenenplan, Caption und CTA.“
- „Erstelle fünf Hooks für ein Reel über häufige Landingpage-Fehler. Wähle den stärksten und begründe die Wahl.“
- „Analysiere meine Caption und verbessere die drei größten Schwachstellen.“
- „Plane fünf Reels für meine Zielgruppe und variiere die Einstiege.“

## Was dieser Skill nicht macht

Er erstellt Texte und Produktionspläne. Video-Rendering, Veröffentlichung und automatisierte Nachrichten benötigen gegebenenfalls separate Werkzeuge. Er garantiert keine Reichweiten oder Verkäufe.

## Nutzung

Die Nutzung des Skills im eigenen Arbeitsablauf ist kostenlos. Es handelt sich um eine eigenständige Anleitung ohne Abhängigkeit von kostenpflichtigen Copywriting-Systemen.
